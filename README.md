# 半米

一间食堂。四十几个人每天中午自己找路、排队打饭、接水、找座位。坐在一张桌上吃几天饭就熟了；熟的人会想坐一起；不坐一起慢慢就生分。怕生的人宁可自己坐一张空桌。每个礼拜一有人转走，有人转来。窗边那块地有太阳的时候，麻雀不去偷老李的馒头，老李心情好，多打一勺土豆，大家吃得久一点。

你能做的只有一件事：推桌子。挨着的桌子会拼成一张大桌，坐一张大桌的人都算同桌。

第一次推的时候，旁边会留一个没被推过的食堂，跟着一起过日子。右边写着两边哪里不一样了：谁只在这边跟谁熟了，谁只在那边。把桌子全推回原处，再过几天看看，变回来的有多少。

吹万写的，从她写的一篇小说《半米》来的。sim.js 是规矩，index.html 是画面。
